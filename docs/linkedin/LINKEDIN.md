# Kit LinkedIn · Guillaume Crespel

Tout ce qu'il faut pour aligner le profil LinkedIn sur guillaumecrespel.fr : mêmes promesses, mêmes chiffres, même univers visuel. Les textes sont prêts à copier, en français puis en anglais (profil secondaire).

Les images se régénèrent depuis le site avec `pnpm generate:linkedin` : si un chiffre ou une application change sur le site, le kit suit.

## Avant de commencer

1. **Désactive le partage des modifications** (Profil > « Partager les modifications du profil » sur Non), sinon chaque champ modifié notifie ton réseau.
2. Mets à jour dans cet ordre : photo, bannière, titre, infos, expériences, services, sélection, compétences.
3. Réactive le partage, puis publie le post de lancement (dernière section). C'est lui qui annonce le tout, une seule fois.
